# POSTX

CREATE ONCE • POST EVERYWHERE

POSTX is a creator-focused social media publishing dashboard.

## Frontend

- index.html
- style.css
- app.js
- config.js

## Backend

The backend will securely handle:

- OAuth
- YouTube uploads
- TikTok publishing
- Instagram publishing
- Facebook publishing
- persistent upload jobs
- upload progress
- retries
- token refresh

## Important

Never put secret API keys or OAuth client secrets inside frontend files.

Social accounts must be connected through official OAuth.

A video is required before POST EVERYWHERE can be used.
